# Site Piracanjuba

Página feita para um trabalho de faculdade, seguindo um wireframe dado pelo professor. O tema escolhido foi a Piracanjuba.

## Tecnologias

- HTML
- CSS

## Como executar

Baixe a pasta e abra o arquivo `index.html` no navegador. Não precisa instalar nada.

## Sobre o projeto

A página tem cabeçalho (logo e duas informações), menu, corpo (imagem e texto) e rodapé (links úteis, fale conosco e redes sociais).

Os ícones são SVG colocados direto no HTML e as cores foram tiradas da logo.

Responsividade:

- Tablet: fontes menores, texto centralizado e imagem do corpo abaixo do texto.
- Celular: logo do cabeçalho menor e sem as informações 1 e 2.

As informações do rodapé (e-mail e telefone) são só de exemplo.
